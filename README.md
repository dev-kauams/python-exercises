## Como usar

Cada pasta representa um projeto independente. Abra a pasta do exercício desejado e siga as instruções do seu README. Não execute todos os projetos como se fossem uma única aplicação.

## Organização e atribuição

Os links para os repositórios de origem são preservados. Confira o README e a licença de cada projeto antes de reutilizar ou redistribuir seu conteúdo. Arquivos grandes e diretórios de dependências/ambientes locais não são copiados.
